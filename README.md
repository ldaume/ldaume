# Leonard Daume

I build agent systems for software development and the harnesses that make agent work reliable: the same context and duties in every session, tests and gates on every change.

People set goals, limits, and veto. Agents carry the work from signal to production, and every change passes tests, security checks, and privacy checks before it merges.

Projects, CV, and contact are on [daume.dev](https://www.daume.dev). Email: [mail@daume.dev](mailto:mail@daume.dev).

## Built in the open

- [Agentic Engineering Skills & Harness](https://github.com/ldaume/agentic-engineering-harness) - the public Skills, repository patterns, and review loops I use to make agent work reliable, from bounded repository tasks to governed value streams.
- [Jev Studio](https://jev-studio.daume.dev) - decision rules for incoming text, written as plain questions, checked on labeled cases, and handed to engineering as typed code with tests.
- [Agentic Engineering Maturity Model](https://www.daume.dev/en/agentic-engineering-maturity-model) - seven levels, from a directly guided task to an adaptive product system.
